## 📖 简介

一个基于浏览器的个人财务管理系统，采用**情景记账**模式，将复杂的财务操作简化为三步：**选场景 → 填金额 → 自动联动**。无需任何构建工具或后端服务，打开即用，数据存储在浏览器本地。

> 🎯 适合场景：个人/家庭日常收支管理、月度财务盘点、资产负债追踪。

---

## ✨ 功能一览

| 功能                | 说明                                                         |
| ------------------- | ------------------------------------------------------------ |
| 🎯 **情景化记账**   | 预置 12 种常见财务情景，覆盖收入、消费、投资、固定资产四大类 |
| 🔗 **自动联动**     | 每笔记账自动同步更新现金、投资、固定资产、负债及利润五大维度 |
| 🧮 **内置计算器**   | 金额输入框支持算式模式（`100+50*2-30/3`），按回车自动计算    |
| 📊 **资产负债盘点** | 实时展示**期初 → 本期变动 → 期末**完整资产负债表             |
| 💾 **快照存档**     | 保存到浏览器缓存、导出/导入 JSON 文件，跨设备迁移数据        |
| 🖼️ **报表导出**     | 支持 PNG 图片下载和 PDF 打印两种格式                         |
| 📋 **暂存确认**     | 记账先入暂存区，审核无误后批量提交到资产负债表               |
| 📝 **快照覆盖**     | 支持覆盖已有存档，类似游戏存档槽位机制                       |

## 🎮 操作流程

```
① 选择大类 ──→ ② 选择情景 ──→ ③ 输入金额 ──→ ④ 确认记账 ──→ ⑤ 提交到资产负债表
```

### 首次使用

打开页面后，左侧显示 **🚀 开始本期** 按钮，提供三种设定期初数据的方式：

| 方式                    | 说明                               |
| ----------------------- | ---------------------------------- |
| 📋 **从历史存档开始**   | 选择已有快照，期末数据转为新时期初 |
| 📁 **从JSON文件导入**   | 导入之前导出的快照文件             |
| ✏️ **手动输入期初数据** | 自行填写各资产负债项目的期初金额   |

设定期初后进入记账主界面。

### 日常记账

1. **选择场景大类** — 工资与收入 / 日常消费 / 投资理财 / 固定资产
2. **选择具体情景** — 如"工资收入"、"投资支出(买入)"等具体场景
3. **输入金额** — 支持算式模式（点击 🔢 切换为 🧮）
4. **点击「✅ 确认记账」** — 记录进入暂存列表（**尚未**更新资产负债表）
5. **检查暂存列表** — 确认无误后点击「✅ 提交到资产负债表」
6. **查看右侧** — 资产负债表实时更新

> 💡 **为什么要两步？** 暂存允许你在提交前检查和修改，避免误操作直接影响资产负债表。

## 🗺️ 情景映射表

系统通过 `SCENARIO_MAP` 定义每类情景对财务数据的影响：

| 字段           | 说明           | 取值                               |
| -------------- | -------------- | ---------------------------------- |
| `asset`        | 影响的资产类型 | `"cash"` / `"investment"` / `null` |
| `amount`       | 资产变动系数   | `1`(增加) / `-1`(减少) / `0`(不变) |
| `liability`    | 影响的负债类型 | `"short"` / `"long"` / `0`         |
| `liabilityDir` | 负债变动方向   | `1`(增加) / `-1`(减少)             |
| `fixedChange`  | 固定资产变动   | `1`(增加) / `0`(不变)              |
| `profit`       | 利润影响       | `1`(收入) / `-1`(支出) / `0`(中性) |

## 🔧 功能详解

### 🧮 内置计算器

点击金额输入框左侧的图标切换模式：

```
🔢 普通模式 → 🧮 计算模式
```

计算模式下支持：`+` `-` `*` `/` `(` `)` `%` 运算。输入 `100+50*2-30/3` 后按回车，自动计算出结果。

### 📋 暂存与提交

记账流程拆分为**暂存**和**提交**两步：

```
确认记账 → 进入暂存列表（资产负债表不变）
                ↓
         点击「提交到资产负债表」（批量生效）
                ↓
         资产负债表实时更新
```

- 暂存列表中的记录可单条删除（✕）或全部清空
- 提交后仍可添加新记录，再次提交
- 页面刷新后暂存数据保留

### 💾 快照系统

**保存快照** → 四种方式：

| 方式              | 存储位置            | 用途                 |
| ----------------- | ------------------- | -------------------- |
| 💻 保存到本地缓存 | 浏览器 localStorage | 快速存档/还原        |
| 📁 导出 JSON 文件 | 下载到电脑          | 永久保存/跨设备迁移  |
| ✅ 两者都要       | 同时                | 推荐，兼顾快速与安全 |
| 📝 覆盖已有存档   | 覆盖已有快照        | 类似游戏存档覆盖     |

**历史存档** → 管理所有快照：

- 查看快照列表（含时间、净资产变化）
- 点击加载快照（期末数据结转为期初）
- 删除或覆盖快照
- 从 JSON 文件导入快照

### 🖨️ 报表导出

- **PNG 图片**：Canvas 渲染资产负债表为 `.png` 文件
- **PDF 文件**：浏览器打印对话框 → 另存为 PDF

## 📊 数据模型

### 数据结构

```
baseData (期初余额)              changes (本期变动)            end (期末余额)
├── cash                         ├── cash                      ├── cash = base + change
├── investment                   ├── investment                ├── investment = base + change
├── fixed                        ├── fixed                     ├── fixed = base + change
├── liabilityShort               ├── liabilityShort            ├── liabilityShort = base + change
└── liabilityLong                └── liabilityLong             ├── liabilityLong = base + change
                                                                 └── profit (利润影响)
```

### 勾稽公式

```
期末流动资产 = 期初流动资产 + 本期现金变动
期末投资资产 = 期初投资资产 + 本期投资变动
期末固定资产 = 期初固定资产 + 本期固定资产变动
期末短期负债 = 期初短期负债 + 本期短期负债变动
期末长期负债 = 期初长期负债 + 本期长期负债变动

资产总计 = 流动资产 + 投资资产 + 固定资产
负债总计 = 短期负债 + 长期负债
净资产   = 资产总计 − 负债总计
```

### localStorage 键

| 键名                | 内容              | 触发时机              |
| ------------------- | ----------------- | --------------------- |
| `finance_BaseData`  | 期初资产负债数据  | 设定期初 / 加载快照   |
| `finance_Changes`   | 本期累计变动      | 提交暂存 / 删除记录   |
| `finance_Pending`   | 暂存记账明细      | 确认记账 / 提交后清空 |
| `finance_BeginTime` | 期初时间          | 开始新的一期          |
| `finance_Snapshots` | 快照列表 (≤50 条) | 保存 / 覆盖 / 删除    |
| `finance_Requests`  | 用户情景建议      | 申请增加              |
