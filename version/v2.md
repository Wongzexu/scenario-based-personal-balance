## 项目定位

基于浏览器的个人财务管理系统，采用**情景记账**模式（选场景 → 填金额 → 自动联动资产负债表）。v2.0 从纯前端项目演进为前后端渐进式架构，保留零依赖打开即用的能力，同时引入 Node.js + Express 后端为云同步、用户系统铺路。

## 核心模块映射

### 前端模块加载链（严格按依赖顺序）

| #   | 文件                             | 职责                                                                   |
| --- | -------------------------------- | ---------------------------------------------------------------------- |
| 1   | `public/js/core/icons-data.js`   | SVG path 数据字典 `ICON_PATHS`                                         |
| 2   | `public/js/config/scenarios.js`  | 情景映射表 `SCENARIO_MAP`（12 种情景）                                 |
| 3   | `public/js/core/storage.js`      | `getBaseData()` / `getChangesData()` / `getSessions()` 等              |
| 4   | `public/js/core/state.js`        | 全局变量、`isPeriodActive()`、`restoreData()`、`updatePeriodDisplay()` |
| 5   | `public/js/core/calculator.js`   | `calculate()` — 汇总变动、计算期末                                     |
| 6   | `public/js/ui/modal.js`          | `openModal()` / `closeModal()` / `switchModal()` / `showToast()`       |
| 7   | `public/js/ui/form.js`           | `confirmTransaction()` / 表单验证                                      |
| 8   | `public/js/ui/render.js`         | `renderPendingList()` / 暂存区、会话列表渲染                           |
| 9   | `public/js/ui/report.js`         | `exportReport()` / `doExportPNG()` / `doExportPDF()`                   |
| 10  | `public/js/snapshot/snapshot.js` | 快照保存 / 加载双模式 / 导入导出                                       |
| 11  | `public/js/app.js`               | 入口初始化、`processDataIcons()`、申请增加                             |
| 12  | `public/js/cloud-sync.js`        | `CloudSpace()` / `CloudSync.ifLinkCloud()`                             |

### 关键函数引用

| 函数                               | 文件            | 说明                            |
| ---------------------------------- | --------------- | ------------------------------- |
| `icon(name, size)`                 | `app.js`        | 生成 SVG HTML 字符串            |
| `processDataIcons()`               | `app.js`        | 将 `[data-icon]` 替换为实际 SVG |
| `confirmTransaction()`             | `form.js`       | 暂存一笔记账                    |
| `calculate()`                      | `calculator.js` | 汇总变动 → 更新界面             |
| `openModal(id)` / `closeModal(id)` | `modal.js`      | 模态框控制                      |
| `switchModal(from, to)`            | `modal.js`      | 模态框间平滑切换                |
| `showToast(msg, type, duration)`   | `modal.js`      | Toast 通知                      |
| `saveSnapshot()`                   | `snapshot.js`   | 保存快照                        |
| `exportReport()`                   | `report.js`     | 打印/导出选择弹窗               |

## 数据模型

### localStorage 键

| 键名                 | 类型   | 内容                                                                 |
| -------------------- | ------ | -------------------------------------------------------------------- |
| `finance_BaseData`   | Object | `{ cash, investment, fixed, liabilityShort, liabilityLong }`         |
| `finance_Changes`    | Object | `{ cash, investment, fixed, liabilityShort, liabilityLong, profit }` |
| `finance_Pending`    | Array  | 暂存记账明细                                                         |
| `finance_BeginTime`  | string | 期初时间 (`toLocaleString("zh-CN")`)                                 |
| `finance_Snapshots`  | Array  | 快照列表 (≤50)                                                       |
| `finance_Sessions`   | Array  | 已提交会话记录                                                       |
| `finance_Requests`   | Array  | 用户情景建议                                                         |
| `finance_MigratedV2` | string | v1→v2 迁移标记                                                       |

### 后端 API

| 端点                    | 方法   | 说明                     |
| ----------------------- | ------ | ------------------------ |
| `/api/hello`            | GET    | 后端连接测试             |
| `/api/users`            | GET    | 获取用户列表             |
| `/api/icons/list`       | GET    | 扫描所有 SVG 文件名      |
| `/api/icons/registered` | GET    | 已注册图标名列表         |
| `/api/icons/paths`      | GET    | 完整 ICON_PATHS 对象     |
| `/api/icons/svg/:name`  | GET    | 获取单个 SVG 内容        |
| `/api/icons/register`   | POST   | 注册图标到 icons-data.js |
| `/api/icons/:name`      | DELETE | 注销图标                 |

## CSS 设计系统

美学方向：**温润务实 (Warm & Practical)**

### 设计令牌

| 类别   | 令牌                                              | 值                    |
| ------ | ------------------------------------------------- | --------------------- |
